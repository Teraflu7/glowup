# GlowUp

Минималистичный landing page в розово-белой палитре для продукта, который помогает формировать полезные привычки и чувствовать себя лучше каждый день.

## Запуск

Откройте `index.html` в браузере или выполните:

```bash
python -m http.server 8000
```

После этого перейдите по адресу `http://localhost:8000`.
