# GlowUp | Web Technologies Final Project

A clean, responsive 7-page habit-building website in the original GlowUp style.

## Pages
Home, Blog, About, FAQ, Habits, Log in / Sign up, Profile.

## Working features
- Responsive navigation via Bootstrap
- Light/dark mode stored in localStorage
- Sign up, log in, profile, log out (localStorage demonstration, not production security)
- Client-side validation with inline messages
- Search, filter, and save completed habits
- Open-Meteo real-time weather with loading and error states

## Run and deploy
Open index.html in a browser, or serve locally with `python3 -m http.server 8000`.
Upload the *contents* of this folder to a GitHub repository and enable GitHub Pages using main / root. Submit the live URL and repository URL. No live hosting has been performed.

## Note
Credentials are stored locally only for the academic demonstration. Do not use real passwords.
